Advanced Android APK Modification Toolkit for unpacking, patching, conversion, and analysis.

Built for reverse engineering workflows, multi-format APK handling, and application modification utilities.

## ✨ Main Features

### 🧳 Unpacker
Advanced APK unpacking engine for protected applications.

**Supports Unpack:**
- DPT (full unpack)
- SecShell (full unpack)
- Arm加固 (full unpack)
- Epic v2 (kill protection + not full static unpack) 

---

### 🔐 Bypass SSL (Flutter)
SSL pinning bypass module for Flutter-based applications.

**What it does:**
- Disables SSL verification logic in Flutter apps
- Helps intercept and analyze network traffic
- Useful for debugging and security testing

---

### 🧪 Smali Patcher
Low-level Dalvik bytecode modification tool.

**What it does:**
- Modify Smali instructions inside APK
- Inject or edit app logic
- Patch behavior directly at bytecode level

---

### ⚙️ Hermes Patcher
React Native Hermes bytecode patching tool.

**What it does:**
- Modify Hermes compiled JavaScript bytecode
- Patch application logic in React Native apps
- Rebuild modified Hermes payloads

---

### 📦 Auto Sign APK
Automatic APK signing utility.

**What it does:**
- Re-sign modified APK files
- Supports custom keystore or default signing
- Ensures APK is installable after modification

---

### 💀 Signature Killer
Signature verification bypass tool.

**What it does:**
- Removes signature validation checks
- Prevents app rejection after modification
- Allows repackaged APK to run normally

---

### 🔄 Format Converter
Convert Android app packages into standard APK.

**Supported formats:**
- APKS → APK
- XAPK → APK
- APKM → APK

**What it does:**
- Extracts split packages
- Merges components into single APK
- Normalizes app structure

---

### 🧬 Universal .SO Patcher (R2)
Native library patching module.

**What it does:**
- Patch `.so` native libraries
- Modify compiled C/C++ logic
- Support multi-architecture binaries (ARM/ARM64)

---

### 📲 Inject Data Account
Data injection utility for application storage.

**What it does:**
- Inject account/session data into apps
- Modify stored user data structures
- Useful for testing and debugging scenarios

---

### 🛡️ Native Protector
Native library protection tool.

**What it does:**
- Adds protection layers to `.so` files
- Obfuscates native logic
- Prevents basic reverse engineering attempts

---

### 🧯 DEX Repair Tool
DEX structure recovery utility.

**What it does:**
- Fix corrupted or broken classes.dex
- Restore invalid DEX structure
- Make APK usable again after damage/modification

---

### 📱 Device Spoofer
Device identity simulation tool.

**What it does:**
- Spoof device fingerprint parameters
- Simulate different Android environments
- Useful for testing compatibility scenarios

---

### ☕ Smali → Java Converter
Code decompilation helper tool.

**What it does:**
- Converts Smali code into Java-like structure
- Improves readability for reverse engineering
- Helps understanding APK logic

---

### ⬇️ PlayStore APK Downloader
Direct APK downloader from Google Play Store.

**What it does:**
- Fetch APK from Play Store links
- Download installable APK packages
- Useful for offline analysis
